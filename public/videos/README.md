# Hero Background Video

Drop your video file here and name it:

```
hero-bg.mp4
```

**Tips for best results:**
- Format: MP4 (H.264 codec for widest browser support)
- Resolution: 1920×1080 or higher (the video scales via `object-fit: cover`)
- Duration: Any — it loops automatically
- File size: Aim for under ~15 MB for fast loading. Use a tool like [Handbrake](https://handbrake.fr/) to compress.
- Content: Works best with slow, atmospheric footage (minimal fast cuts)

The video plays **autoplay, muted, looped** in the background of the Hero section.
A dark gradient overlay sits on top for text legibility.
